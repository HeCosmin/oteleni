Settings & APIs

Settings are password-free on your private home network. Access to settings is blocked for non-private network clients. Disable router port forwarding when remote access is not needed. API secrets stay on the server.

OMDb metadata

Use the API key from your OMDb email. It stays on the server. Leave blank after reload to keep the saved key.

FileList API

For security, saved passkeys are never sent back to the browser. Leave blank to keep the existing passkey.
Leave empty to search all categories. Use only category IDs supported by your account/API.

Subtitle translation (LibreTranslate)

Use your own LibreTranslate-compatible server. Do not expose API keys in public pages.

External video player

On Windows, CineWave can launch a local file with the selected player. Set the executable path if it is not installed in a standard location.

External playback quality

This selects a preference for the external player workflow. Resolution conversion requires an installed FFmpeg transcoding pipeline; without it, VLC opens the original file.
The selected threshold controls when CineWave attempts to open the external player.
